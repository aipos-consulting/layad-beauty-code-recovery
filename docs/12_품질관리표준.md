# 품질관리 표준

## 1. 품질 목표

기능 구현 여부뿐 아니라 사용성, 데이터 정확성, 보안, 운영 복구 가능성을 함께 검증한다.

## 2. 사용자 경로 체크리스트

- 첫 화면 정상 진입
- 20문항 테스트 완료
- Beauty Code 정확한 산출
- 16유형 직접 선택
- 연령대 선택 또는 응답하지 않음
- 익명 세션 저장
- 상품명·링크 신청
- 분석 상태 표시
- 사용자 유형 점수·등급·순위
- 16유형 히트맵
- 오류 시 다음 행동 안내

## 3. 관리자 경로 체크리스트

- `/admin` 진입
- 데스크톱 메뉴 전체 표시
- 모바일 햄버거 메뉴 전체 표시
- 사용자 통계 조회
- 연령대·국가·지역 집계
- 상품 신청 조회
- 신청자 유형과 적합도 구분
- 16유형 점수 입력
- 임시저장·공개 구분
- 결과 저장 후 사용자 화면 반영

## 4. 데이터 검증

- 전체 합계와 상세 합계 일치
- 테스트와 직접 선택 구분
- 연령대 `응답하지 않음` 누락 없음
- 국가·지역 확인 불가 별도 집계
- 상품당 16유형 점수 존재
- Beauty Code 중복 없음
- 점수 0~100
- 사용자 세션과 상품 신청 연결
- 테스트 데이터 식별·삭제 가능

## 5. 모바일 검증

- 360px 수준의 작은 화면에서 핵심 기능 접근
- 가로 잘림 없음
- 입력창과 버튼 사용 가능
- 모달 내용 스크롤 가능
- 키보드 표시 시 버튼 접근 가능
- 메뉴 선택 후 닫힘
- 긴 상품명·링크 줄바꿈

## 6. 보안 검증

- 비밀키 브라우저 노출 없음
- 관리자 기능 인증 여부
- Supabase 권한 최소화
- 원 IP와 직접 식별정보 미노출
- 입력값 길이와 URL 형식 검증
- 오류 메시지에 내부 정보 미노출

## 7. 배포 판정

- 성공: 빌드·배포·핵심경로·DB 검증 모두 통과
- 조건부 성공: 비핵심 경고만 존재하고 영향이 문서화됨
- 실패: 핵심경로 중단, 데이터 오류, 권한 오류, 배포 미완료

## 8. 결함 기록

결함마다 다음을 기록한다.

- 발생 화면과 시간
- 재현절차
- 기대 결과와 실제 결과
- 환경과 브라우저
- 로그 또는 오류 코드
- 영향도와 우선순위
- 수정 커밋
- 재검증 결과
