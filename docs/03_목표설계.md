# 목표 설계

## 1. 핵심 방향

LAYAD의 모든 상품 신청 기능은 다음 질문에 답해야 한다.

> 선택한 상품이 회원님의 Beauty Code와 얼마나 잘 맞는가?

## 2. 사용자 결과 우선순위

1. 상품명
2. 회원님의 Beauty Code
3. 해당 유형 적합도 점수
4. 감성적 평가 문구
5. 16유형 중 순위
6. 최고 적합 유형과 점수 차이
7. 축별 일치·불일치 설명
8. 16유형 적합도 히트맵
9. 분석 근거와 주의사항

## 3. 적합도 등급

- 90~100: 매우 잘 맞아요
- 75~89: 잘 맞아요
- 60~74: 무난하게 맞아요
- 40~59: 일부 특성이 맞지 않을 수 있어요
- 0~39: 다른 상품을 함께 비교해 보세요
- 미분석: 적합도를 확인하고 있어요

## 4. 사용자 상품 신청 목록

각 신청 건에 다음을 표시한다.

- 신청 상품
- 회원 Beauty Code
- 해당 유형 점수와 등급
- 16유형 내 순위
- 분석 상태
- 결과 보기 또는 진행상태 보기

## 5. 관리자 상품 신청

다음 세 개를 혼용하지 않는다.

- 신청자 유형
- 상품 신청 유형 분포
- 상품 적합도 점수

최근 신청 목록에는 신청자의 실제 적합도 점수·등급·순위를 우선 표시한다.

## 6. 히트맵

상품별 16유형 점수를 4×4 히트맵으로 표시한다.

- 사용자 유형: 굵은 테두리
- 최고점 유형: 최고 적합 배지
- 사용자 유형과 최고점이 같음: 나에게 최적
- 미등록 점수: 미분석
- 모바일 2열, 데스크톱 4열 이상

관리자 화면에서는 여러 상품을 행으로, 16유형을 열로 배치한 비교 히트맵도 제공한다.

## 7. 통계 목표

- 연령대별 사용자 수와 상위 Beauty Code
- 국가별 사용자 수
- 대한민국 광역 지역별 사용자 수
- 지역별 상위 Beauty Code
- 지역 확인 불가 비율
- 상품별 신청 유형 분포
- 적합도 등급별 신청 건수

## 8. 향후 확장

- 회원 계정과 결과 이력
- 사용자 유형 기준 상품 비교
- 가격대·국가별 상품 추천
- 운영자 검수 후 자동분석
- 분석 버전과 근거 관리
- 추천 결과 반응 데이터 수집
