# LAYAD 문서 지식저장소

이 폴더는 LAYAD 프로젝트와 향후 AI 컨설팅 사업에 재사용할 **AI 프로젝트 운영 표준(AIPOS)**을 관리한다.

## 기본 원칙

- 운영 중인 MVP와 차기 설계는 분리한다.
- 대화에서 결정된 사항은 문서에 반영된 뒤 개발한다.
- 사업자료, 제품설계, 기술자료를 구분한다.
- 사용자가 명시적으로 개발 또는 배포를 승인하기 전에는 운영 코드와 DB를 변경하지 않는다.
- 모든 요구사항은 상태와 근거를 가진다.

## 요구사항 상태

`아이디어 → 설계확정 → 개발완료 → 배포완료 → 운영검증`

영문 상태값이 필요한 자동화 도구에서는 다음 값을 사용한다.

`IDEA → DESIGNED → DEVELOPED → DEPLOYED → VERIFIED`

## 2트랙 운영

- **트랙 A:** 현재 운영 MVP의 안정화, 오류 수정, 데이터 보호
- **트랙 B:** 목표 설계, 기술 표준, 차기 기능, AI 실험, 컨설팅 자산화

트랙 B 문서는 운영 배포 대상이 아니다.
