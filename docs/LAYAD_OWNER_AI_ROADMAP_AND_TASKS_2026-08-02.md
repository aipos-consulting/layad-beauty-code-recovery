# LAYAD 오너 추진과업 및 AI 고도화 로드맵

- 작성일: 2026-08-02
- 목적: 2027년 초기창업 투자·창업지원사업 제출 및 실제 서비스 검증

## 1. 현재 MVP

현재 MVP는 20문항, 4축(O/D, G/M, P/C, V/E), 축별 5문항, 선택 코드별 1점, 축별 3점 이상 코드 판정, 16유형 결과를 제공한다.

제품 적합도 분석 Beta는 사용자의 4자리 Beauty Code와 사전에 등록한 제품 특성 코드를 비교해 0~100점으로 계산한다. 이 기능은 사용자 반응을 수집하기 위한 초기 가설 검증 기능이다.

## 2. 오너가 즉시 추진할 과업

### A. 제품 데이터 정비

1. 초기 검증 제품 20~30개 선정
2. 제품명, 브랜드, 카테고리, 가격대, 국가, 공식 제품 설명 기록
3. 제품별 O/D, G/M, P/C, V/E 적합 코드와 축별 중요도 결정
4. 제품 평가 근거와 평가자를 기록
5. 제품 리뉴얼 시 버전과 평가일 갱신

### B. 사용자 검증 설계

1. 테스트 완료 후 제품 적합도에 대한 `맞아요 / 보통 / 안 맞아요` 수집
2. 실제 사용 여부 구분
3. 만족도 1~5점, 재사용 의향, 구매 의향 수집
4. 제품별 최소 30건 이상의 피드백 확보
5. 16유형별 데이터 편중을 매월 확인

### C. 데이터 목표

- 500건: 문항과 유형 분포 검증
- 2,000건: 제품 적합도 Beta 보정
- 제품 평가 500건 이상: 초기 통계 모델 검토
- 5,000건 이상: 초기 AI 개인화 모델 개발 검토
- 10,000건 이상: 국가·연령·행동 데이터를 포함한 고도화 검토

단순 테스트 완료 건수보다 실제 제품 사용·만족도·클릭·저장·구매와 같은 정답 데이터가 중요하다.

### D. 운영 및 법적 준비

1. 개인정보 최소수집 원칙 확정
2. 이용약관, 개인정보처리방침, 마케팅 동의 구분
3. 제품 적합도가 의학적 진단이나 효능 보장이 아님을 안내
4. 제품사 협찬·광고·제휴 여부 표시 기준 마련
5. 문항, 분류체계, 데이터셋의 버전과 변경이력 관리

## 3. 단계별 AI 로드맵

### 단계 1 — 규칙 기반 MVP

- 20문항과 16유형 분류
- 제품 특성과 사용자 코드의 규칙 기반 적합도
- 목표: 서비스 수요와 데이터 수집 가능성 검증

### 단계 2 — 통계 기반 적합도 보정

- 사용자 만족도와 실제 사용 데이터를 활용한 가중치 보정
- 유형별 제품 만족도 차이 분석
- 목표: 초기 규칙의 정확도 개선

### 단계 3 — AI 개인화

- Beauty Code, 국가, 연령대, 제품 특성, 만족도, 재방문, 클릭, 구매 데이터를 활용
- 사용자별 제품 적합 확률 또는 순위 모델 개발
- 목표: 같은 Beauty Code 안에서도 개인별 차이를 반영

## 4. 월별 핵심지표

- 테스트 시작 수
- 테스트 완료 수와 완료율
- 16유형 분포
- 결과 재방문 수
- 제품 적합도 조회 수
- 제품별 맞음/보통/안 맞음
- 실제 사용 후 만족도
- 제품 클릭률과 구매 전환율
- 국가·연령대별 차이

## 5. 투자·지원사업용 설명

LAYAD는 규칙 기반 Beauty Code MVP로 사용자 유형과 행동 데이터를 검증하고, 제품 특성과 Beauty Code의 적합도 가설을 시험한다. 이후 실제 사용 만족도와 행동 데이터를 축적하여 통계 기반 가중치를 보정하고, 충분한 정답 데이터가 확보된 뒤 AI 개인화 추천 모델로 고도화한다.

## 6. 현재 제품 적합도 Beta의 제한

- 현재 점수는 사전 정의된 제품 특성과 Beauty Code 일치도를 계산한 가설이다.
- 과학적·임상적 효능을 보장하지 않는다.
- 피부 상태, 계절, 환경, 사용량에 따라 실제 사용감은 달라질 수 있다.
- 제품별 사용자 피드백이 축적되면 점수와 가중치를 재조정한다.
