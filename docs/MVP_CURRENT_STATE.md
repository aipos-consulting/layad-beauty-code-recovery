# LAYAD MVP Current State

기준일: 2026-08-03

## 운영 구성

- 프론트엔드/서버: Next.js, Vercel
- 데이터베이스: Supabase
- 관리자 주소: `/admin`
- AI 분석: OpenAI API 미사용, 운영자 ChatGPT Plus 수동 분석 방식

## 현재 구현된 핵심 사용자 기능

- 20문항 Beauty Code 테스트
- 이미 유형을 아는 사용자의 16유형 직접 선택
- 연령대 선택
- 상품명 또는 상품 링크 신청
- 상품 신청 저장
- 분석 대기 상태 표시

## 현재 구현된 관리자 기능

- 통합 `/admin` 화면
- 대시보드
- 사용자 유형 통계
- 상품 신청 조회
- 분석 작업 UI
- 상품 관리 UI
- 적합도 결과 입력 UI
- 운영 설정 UI
- 모바일 햄버거 메뉴
- 연령대·국가·지역 집계 API 및 화면

## 현재 DB 핵심 테이블

- `test_sessions`
- `product_analysis_requests`
- 선택적으로 `product_type_fits`

## 현재 알려진 위험과 제한

- 관리자 인증이 아직 적용되지 않은 프로토타입 상태
- 적합도 결과 저장·공개 전체 흐름은 완성 전
- 사용자별 상품 적합도 결과 화면은 목표 설계 상태
- 상품별 16유형 점수표와 히트맵은 목표 설계 상태
- 테스트 데이터와 실제 데이터가 함께 보일 수 있으므로 식별자 관리 필요
- 문서와 코드가 완전히 동기화되어 있지 않음

## 안정화 기준

현재 운영 기능을 수정할 때는 다음 경로가 깨지지 않아야 한다.
- 테스트 시작과 완료
- 직접 유형 선택
- 연령대 선택
- 상품 신청 저장
- 관리자 통계 조회
- 모바일 관리자 메뉴 접근
