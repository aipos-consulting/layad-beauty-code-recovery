# LAYAD 프로젝트 헌장

## 1. 프로젝트 목적

LAYAD BEAUTY CODE는 20문항 또는 직접 선택을 통해 사용자의 16가지 메이크업 유형을 확인하고, 선택한 상품이 회원님의 Beauty Code와 얼마나 잘 맞는지 알려주는 서비스다.

## 2. 핵심 가치

> 선택하신 상품이 회원님의 Beauty Code와 얼마나 잘 맞는지 확인해 보세요.

서비스의 중심은 상품 인기나 단순 유형 통계가 아니라 **사용자 유형과 선택 상품의 적합도**다.

## 3. 대상 사용자

- 자신의 메이크업 성향을 알고 싶은 사용자
- 특정 화장품이 자신에게 잘 맞을지 확인하고 싶은 사용자
- 유형·연령·지역·상품 신청 데이터를 운영하는 관리자

## 4. Beauty Code 체계

- O: 지성형
- D: 건성형
- G: 글로우 선호
- M: 매트함 추구
- P: 정교함 추구
- C: 간편함 추구
- V: 변동형
- E: 일관형

4개 축의 조합으로 16유형을 구성한다.

## 5. MVP 범위

- 20문항 테스트
- 16유형 직접 선택
- 선택형 연령대 수집
- 익명 세션 저장
- 상품명 또는 공개 링크 신청
- 관리자 통합화면
- 사용자·연령·국가·지역 통계
- 운영자 수동 16유형 적합도 입력
- 사용자 유형 적합도와 16유형 히트맵 표시

## 6. MVP 제외 범위

- OpenAI API 기반 자동 리뷰분석
- 회원가입과 개인계정 기반 장기이력
- 자동 상품추천 엔진
- 결제·제휴·상거래
- 의료적 피부진단

## 7. 절대 원칙

- 사용자의 Beauty Code 적합도를 결과 화면의 최우선 정보로 표시한다.
- 분석 근거가 없는 임의 점수를 제공하지 않는다.
- 원 IP, 생년월일, 직접 식별정보를 저장하지 않는다.
- 운영자 수동분석과 향후 AI 자동분석을 구분한다.
- 운영 MVP의 안정성을 차기 기능보다 우선한다.

## 8. 성공 기준

- 사용자가 유형 확인부터 상품 신청까지 중단 없이 완료한다.
- 관리자가 신청과 통계를 정확히 조회한다.
- 상품 하나에 16유형 점수가 중복 없이 저장된다.
- 사용자의 유형 점수·등급·순위가 정확히 표시된다.
- 테스트 데이터와 실제 데이터를 구분하고 삭제할 수 있다.
