# 제품 적합도 분석 운영기준

## 핵심 원칙

LAYAD의 제품 적합도 분석은 실제 사용자 리뷰를 근거로 한다.

- 공식 제품 설명은 보조정보로만 사용한다.
- 리뷰 근거가 없는 제품에는 임의의 적합도 점수를 부여하지 않는다.
- 제품별 유효 리뷰 수, 긍정·부정 신호, 실제 구매 여부, 협찬 여부, 작성 시점과 제품 버전을 구분한다.
- 리뷰가 부족하면 점수 대신 `데이터 부족` 또는 `검증 중`으로 표시한다.

## 리뷰에서 수집할 항목

- 유분과 건조 관련 경험
- 글로우와 매트 표현
- 정교한 사용과 간편한 사용
- 환경·컨디션에 따른 변화와 안정성
- 지속력, 밀림, 들뜸, 번들거림, 당김
- 만족도, 재사용 의향, 재구매 의향
- 계절, 기후, 사용 기간, 사용량

## MVP Beta 표시 기준

- 제품별 유효 리뷰 30건 미만: 데이터 부족
- 제품별 유효 리뷰 30건 이상: 초기 적합도 Beta 표시 가능
- 점수와 함께 리뷰 수, 주요 긍정 근거, 주요 주의 의견, 신뢰도를 표시한다.

## 향후 AI 적용

초기에는 리뷰 신호와 Beauty Code를 규칙 기반으로 비교한다. 이후 리뷰와 LAYAD 자체 사용후기가 충분히 축적되면 자연어 리뷰 분석과 개인화 순위 모델로 고도화한다.
