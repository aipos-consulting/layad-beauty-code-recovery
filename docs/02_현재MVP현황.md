# 현재 MVP 현황

## 1. 문서 목적

이 문서는 목표 설계가 아니라 현재 실제로 구현·배포된 상태를 기록한다. 운영주소에서 확인되지 않은 항목은 완료로 표시하지 않는다.

## 2. 기술 구성

- 프론트엔드·API: Next.js
- 소스·문서 관리: GitHub
- 데이터베이스: Supabase PostgreSQL
- 배포: Vercel
- 상품 분석: MVP에서는 운영자가 ChatGPT Plus 등 외부 분석도구를 활용해 수동 수행
- OpenAI API: 사용하지 않음

## 3. 사용자 기능

- 첫 화면에서 20문항 테스트 또는 16유형 직접 선택
- 20문항 결과로 Beauty Code 생성
- 직접 선택 화면에서 16유형 선택
- 연령대 선택 또는 응답하지 않음
- 익명 세션 저장
- 상품명 또는 공개 상품 링크 신청
- 신청 상태와 분석 결과 표시 구조

## 4. 관리자 기능

관리자 주소는 `/admin` 하나를 사용하며 같은 화면에서 메뉴를 전환한다.

- 대시보드
- 사용자 통계 상세
- 상품 신청 정보
- 분석 작업
- 상품 관리
- 적합도 결과
- 운영 설정

## 5. 현재 데이터 범위

- Beauty Code와 선택 방식
- 선택형 연령대
- 국가코드와 광역 지역코드
- 상품 신청값과 상태
- 상품 기본정보
- 상품별 Beauty Code 점수

직접 식별정보와 원 IP는 수집 대상이 아니다.

## 6. 운영상 확인이 필요한 항목

- 실제 Vercel 배포 완료 여부
- 사용자 테스트·직접 선택 전체 흐름
- 모바일 관리자 전체 메뉴
- Supabase 테이블과 권한
- 운영자 점수 저장 API
- 상품당 16개 점수 저장 여부
- 사용자 결과 화면의 점수·순위·히트맵
- 테스트 데이터 일괄 삭제

## 7. 알려진 구조적 한계

- 관리자 인증이 없는 프로토타입 단계일 수 있음
- 운영자 수동분석으로 처리시간이 길 수 있음
- 상품 중복 식별과 정규화가 제한적임
- 사용자 계정이 없어 다른 기기에서 결과 이력을 이어보기 어려움
- 자동 리뷰수집·AI 분석은 MVP 범위에서 제외됨

## 8. 현황 기록 규칙

기능 상태는 다음 근거가 있을 때만 갱신한다.

- `DEVELOPED`: 코드 커밋 확인
- `DEPLOYED`: 배포 성공 확인
- `VERIFIED`: 실제 화면·DB 연결 테스트 완료

단순 설계 또는 대화 중 합의는 현재 현황에 포함하지 않는다.
