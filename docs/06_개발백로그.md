# 개발 백로그

## 우선순위 기준

- P0: 운영 장애·데이터 손실·보안 위험
- P1: 핵심 사용자 가치와 직접 연결
- P2: 운영 효율과 분석 품질 향상
- P3: 확장 기능

## P0 안정화

- 관리자 인증 적용
- Supabase 권한과 서버키 사용구조 점검
- 운영 배포 성공·실패 이력 확인
- 사용자 테스트·직접선택·상품신청 회귀 테스트
- 테스트 데이터 식별·일괄 삭제 검증
- 오류 발생 시 사용자 메시지 표준화

## P1 핵심 가치

- 사용자 유형별 상품 적합도 점수·등급·순위
- 상품별 16유형 점수분포표
- 4×4 적합도 히트맵
- 사용자 유형과 최고 적합 유형 강조
- 관리자 최근 신청에 개별 적합도 표시
- 상품별 점수 저장·공개·검수 흐름

## P2 운영 개선

- 상품 중복 식별과 정식 상품명 관리
- 신청 유형 분포와 실제 적합도 비교
- 연령·국가·지역별 상품 관심도
- 분석 버전, 근거, 주의사항 관리
- 상품별 처리상태와 담당자 관리
- 관리자 검색·필터·정렬

## P3 확장

- 회원가입과 신청 결과 이력
- 사용자 유형 기준 상품 비교
- 가격대별 추천
- 국가별 상품 추천
- 추천 반응과 전환 데이터
- 운영자 검수 기반 AI 자동분석

## 백로그 운영 규칙

- 항목마다 요구사항 ID와 상태를 연결한다.
- 개발 전 테스트 기준을 작성한다.
- 한 번에 하나의 검증 가능한 단위로 개발한다.
- 완료된 항목은 삭제하지 않고 완료일·커밋·검증결과를 기록한다.
- 운영 안정화 작업이 차기 기능보다 우선한다.
