# 사용자 UX 표준

## 1. 핵심 질문

사용자 상품 신청 화면은 항상 다음 질문에 답해야 한다.

> 선택하신 상품이 회원님의 Beauty Code와 얼마나 잘 맞는지 확인해 보세요.

## 2. 화면 흐름

첫 화면 → Beauty Code 테스트 또는 직접 선택 → 연령대 선택 → 상품 신청 → 분석 상태 → 사용자 유형 적합도 결과 → 16유형 비교

## 3. 결과 정보 우선순위

1. 상품명
2. 회원님의 Beauty Code
3. 해당 유형 적합도 점수
4. 자연스러운 평가 문구
5. 16유형 내 순위
6. 최고 적합 유형과 차이
7. 축별 설명
8. 16유형 히트맵
9. 분석 근거와 주의사항

## 4. 문구 원칙

기술 용어보다 사용자 경험을 우선한다.

- 지양: 적합도 알고리즘 실행, 유형 매칭 처리
- 권장: 얼마나 잘 맞는지 확인해 보세요
- 지양: 분석 실패
- 권장: 현재 상품 정보를 충분히 확인하기 어려워 결과를 제공하지 못했습니다

버튼은 짧고 안내 문장은 충분히 설명한다.

## 5. 상태별 화면

### 신청 전

- 회원 Beauty Code 표시
- 상품명 또는 링크 입력
- 개인정보 최소수집 안내

### 신청 완료

- 상품명
- 회원 Beauty Code
- 처리 단계
- 예상되는 다음 결과

### 분석 완료

- 사용자 점수를 가장 크게 표시
- 점수 의미를 문장으로 설명
- 다른 유형과 비교 가능하게 표시

### 분석 불가

- 원인을 이해하기 쉽게 설명
- 정확한 상품 링크 재입력 등 다음 행동을 안내

## 6. 히트맵 원칙

- 모바일 2열, 데스크톱 4열 이상
- 회원 유형은 굵은 테두리
- 최고점 유형은 별도 배지
- 회원 유형이 최고점이면 `나에게 최적`
- 색상만으로 의미를 전달하지 않고 점수·문구 병기

## 7. 접근성과 모바일

- 선택 영역 최소 높이 44px
- 글자와 배경 대비 확보
- 버튼 비활성 원인 표시
- 가로 스크롤에 핵심 기능을 숨기지 않음
- 진행 중 화면에서 멈춘 것으로 오해하지 않도록 단계 표시

## 8. 신뢰 원칙

- 근거 없는 점수 표시 금지
- 의료적 진단처럼 표현하지 않음
- 점수는 절대적 사실이 아니라 정해진 분석 기준에 따른 결과임을 설명
- 미분석과 낮은 점수를 명확히 구분
