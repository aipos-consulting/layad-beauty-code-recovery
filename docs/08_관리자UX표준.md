# 관리자 UX 표준

## 1. 통합화면 원칙

관리자 주소는 `/admin` 하나를 사용하고 메뉴 선택 시 같은 화면에서 내용을 전환한다.

메뉴 순서:

1. 대시보드
2. 사용자 통계 상세
3. 상품 신청 정보
4. 분석 작업
5. 상품 관리
6. 적합도 결과
7. 운영 설정

## 2. 대시보드

사용자 통계와 상품 신청 현황을 함께 보여준다.

핵심 지표:

- 전체 유형조회
- 20문항 테스트 완료
- Beauty Code 직접 선택
- 상품 신청 건수
- 분석 완료 건수
- 적합도 등급별 신청 건수
- 분석 대기 건수

## 3. 최근 상품 신청

단순 최고점 유형만 표시하지 않는다.

필수 정보:

- 상품명
- 신청자 Beauty Code
- 해당 사용자 유형 적합도 점수
- 적합도 등급
- 16유형 중 순위
- 분석 상태
- 신청일

## 4. 상품 상세

정보 배치 순서:

1. 사용자-상품 적합도 요약
2. 16유형 적합도 히트맵
3. 16유형 점수분포표
4. 신청자 유형 분포
5. 연령대 분포
6. 국가·지역 분포
7. 분석 근거와 버전

## 5. 적합도 결과 입력

- 상품과 신청건 선택
- 16유형 점수 0~100 입력
- 누락·중복 검증
- 분석 요약·근거·주의사항 입력
- 임시저장과 공개를 구분
- 공개 전 16개 점수 존재 여부 확인

## 6. 모바일 메뉴

- 상단 LAYAD 로고와 `관리자 화면`
- 우측 햄버거 버튼
- 전체 7개 메뉴를 세로 목록으로 표시
- 선택 후 자동 닫힘
- 현재 메뉴 강조
- 메뉴 밖 선택 또는 ESC로 닫힘
- 화면 높이를 넘으면 세로 스크롤

## 7. 관리자 신뢰성

- 신청자 유형과 상품 최고 적합 유형을 구분
- 분석 대기와 오류를 구분
- 테스트 데이터에 명확한 표식
- 저장·공개·삭제 작업은 결과 메시지 제공
- 민감한 키와 원 IP를 표시하지 않음
- 관리자 인증 전에는 외부 공개 금지
