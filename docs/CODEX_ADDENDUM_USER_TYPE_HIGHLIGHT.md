# Codex 보완 지시: 사용자 유형 적합도 강조 UI

## 목적

상품별 16유형 적합도 중 현재 사용자의 `finalCode`와 일치하는 적합도가 화면에서 즉시 구분되도록 강조한다.

## 적용 범위

- 기존 `docs/CODEX_TASK_REVIEW_AI_PRODUCT_FIT_IMPLEMENTATION.md`의 계산 구조와 데이터 모델은 변경하지 않는다.
- 기존 20문항, 점수 계산, 16유형 생성 규칙은 변경하지 않는다.
- 이번 보완은 결과 화면 UI 강조 규칙만 추가한다.

## UI 요구사항

각 상품 카드에서 현재 사용자의 Beauty Code와 일치하는 적합도 영역을 다음과 같이 강조한다.

1. 강조 대상 조건

```ts
const isCurrentUserType = productTypeFit.beautyCode === finalCode;
```

2. 강조 대상에는 일반 행·카드와 다른 배경색을 적용한다.

권장 스타일:

```text
배경: 연한 블러시 핑크
테두리: LAYAD 메인 핑크
텍스트: 기존 가독성 유지
```

Tailwind 예시:

```tsx
className={isCurrentUserType
  ? "border-[#d88c9c] bg-[#fff0f2] ring-1 ring-[#e4aab5]"
  : "border-[#efdee1] bg-white"
}
```

3. 강조 영역 안에 다음 배지를 표시한다.

```text
내 유형
```

또는

```text
MY TYPE
```

한국어 화면에서는 `내 유형`을 우선 사용한다.

4. 현재 사용자 유형 코드를 적합도 점수와 가까운 위치에 표시한다.

예:

```text
내 유형 OGPV
적합도 87%
```

5. 색상만으로 상태를 전달하지 않는다.

반드시 `내 유형` 배지 또는 텍스트를 함께 표시해 접근성을 확보한다.

6. 모바일에서도 배경색, 테두리, 배지가 잘리지 않아야 한다.

7. 다크모드는 이번 범위에 포함하지 않는다.

## 16유형 전체 표를 표시하는 경우

상품 상세 또는 관리자 화면에서 16유형 전체 적합도를 표나 그리드로 표시할 경우:

- `beautyCode === finalCode`인 한 셀 또는 한 행만 강조한다.
- 다른 15개 유형은 중립 배경을 사용한다.
- 강조 행은 표 안에서 스크롤 후에도 식별 가능해야 한다.
- 동일 상품에서 두 개 이상의 행을 `내 유형`으로 강조하면 안 된다.

## 결과 화면 카드만 표시하는 경우

현재 결과 화면처럼 상품별로 사용자의 유형 적합도 1건만 표시하는 경우:

- 해당 적합도 블록 전체에 강조 배경을 적용한다.
- 상단 또는 점수 옆에 `내 유형` 배지를 표시한다.
- 상품 카드 전체를 과도하게 진한 색으로 채우지 말고, 적합도 영역을 중심으로 강조한다.

## 수동 확인

1. 테스트 완료 후 `finalCode` 생성
2. 각 상품에서 `beautyCode === finalCode`인 적합도만 조회
3. 해당 적합도 영역에 강조 배경 표시
4. `내 유형` 배지 표시
5. 다른 유형이나 다른 행이 중복 강조되지 않음
6. 모바일 화면에서 가독성 유지
