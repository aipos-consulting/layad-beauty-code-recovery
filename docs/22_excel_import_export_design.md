# LAYAD 운영 데이터 Excel Import/Export 설계

## 1. 목적

외부 서비스(Smore, Google Forms, Naver Form 등)에서 수집된 데이터를 LAYAD 표준 Excel 형식으로 정리해 운영자가 업로드할 수 있도록 한다. 외부 시스템별 전용 변환 로직을 만들지 않고, 하나의 표준 양식만 지원한다.

## 2. 관리자 메뉴 구조

- 운영 데이터 관리
  - 상품 신청
  - 상품
  - 테스트 세션
  - 변경 이력
  - Excel Import
  - Excel Export
  - Import 결과
  - Import 로그

## 3. 표준 Excel 양식

시트명: `LAYAD_IMPORT`

| 컬럼 | 필수 | 형식/허용값 | 설명 |
|---|---|---|---|
| Product Name | 필수 | 문자열 | 상품명 |
| Brand | 선택 | 문자열 | 브랜드 |
| Category | 필수 | 문자열 | 상품 카테고리 |
| Beauty Code | 필수 | 16개 공식 코드 | 신청자 유형 |
| Country | 선택 | ISO 국가코드 | 예: KR, JP, US |
| Gender | 선택 | F / M / N | 성별 |
| Age Band | 선택 | 14-19, 20-29, 30-39, 40-49, 50-59, 60+, prefer_not_to_say | 연령대 |
| Analysis Date | 선택 | YYYY-MM-DD | 분석일 |
| Summary | 선택 | 문자열 | 상품 분석 요약 |
| OGPV ~ DMCE | 필수 | 0~100 정수 | 16유형 적합도 점수 |
| Status | 필수 | completed / hold | 공개 완료 또는 보류 |

## 4. Beauty Code 허용값

`OGPV`, `OGPE`, `OGCV`, `OGCE`, `OMPV`, `OMPE`, `OMCV`, `OMCE`, `DGPV`, `DGPE`, `DGCV`, `DGCE`, `DMPV`, `DMPE`, `DMCV`, `DMCE`

## 5. 운영 화면

### 5.1 Excel Import

- `양식 다운로드`
- 파일 선택
- 업로드 전 미리보기
- 전체 건수, 정상, 중복, 오류 건수 표시
- `검증 실행`
- 검증 완료 후 `적재 실행`
- 실제 적재 전 Master 관리자 확인

### 5.2 Excel Export

- 데이터 구분 선택
  - 상품 및 적합도 결과
  - 상품 신청
  - 테스트 세션 통계용 익명 데이터
- 상태 및 기간 조건
- `Excel 다운로드`
- Import와 동일한 표준 컬럼 순서를 우선 사용

### 5.3 Import 결과

- 총 건수
- 성공
- 중복
- 오류
- 보류
- 처리 시작·완료 시각

### 5.4 Import 로그

- 작업 ID
- 파일명
- 실행자
- 실행 시각
- 총 건수
- 성공/실패 건수
- 처리 상태
- 원본 파일 보관 여부
- 오류 파일 다운로드

## 6. 검증 규칙

- 필수 컬럼 존재 여부
- 시트명 `LAYAD_IMPORT` 확인
- Beauty Code 허용값 확인
- 16개 점수 모두 존재
- 점수는 0~100 정수
- 모든 점수가 0이거나 동일한 경우 오류 처리
- Status 허용값 확인
- 날짜 형식 확인
- 중복 판정: `Product Name + Beauty Code`

## 7. 중복 처리 정책

업로드 시 운영자가 다음 중 하나를 선택한다.

- 건너뛰기
- 기존 데이터 업데이트
- 새 버전으로 저장

기본값은 `건너뛰기`로 한다. 기존 데이터를 덮어쓰는 경우 변경 사유와 감사 이력을 반드시 남긴다.

## 8. 오류 처리

오류 행은 적재하지 않고 별도 Excel로 제공한다.

오류 파일 기본 컬럼:

- Row Number
- Product Name
- Beauty Code
- Error Code
- Error Message

정상 행만 부분 적재할지, 전체 취소할지는 업로드 전 운영자가 선택한다. 기본값은 `정상 행만 적재`로 한다.

## 9. 개인정보 원칙

- 이름과 이메일은 표준 Import 양식에 포함하지 않는다.
- 회원 계정 연결은 기본적으로 수행하지 않는다.
- 외부 데이터는 익명 통계 또는 상품 적합도 데이터로 적재한다.
- 개인정보가 포함된 외부 파일은 업로드 전에 제거하거나 가명화한다.

## 10. 권한

### Master 관리자

- 양식 다운로드
- Import 검증 및 실제 적재
- 중복 업데이트 승인
- Export 실행
- 오류 파일 다운로드
- Import 로그 조회

### 일반 운영자

- 양식 다운로드
- 파일 업로드 및 검증
- 오류 확인
- 실제 적재 요청

일반 운영자는 실제 적재와 기존 데이터 업데이트를 단독 실행할 수 없다.

## 11. 감사 이력

모든 Import/Export 작업에 다음을 기록한다.

- 작업 ID
- 실행자
- 작업 종류
- 파일명
- 처리 건수
- 처리 결과
- 실행 시각
- 변경 사유

## 12. 인수 기준

1. 운영자가 표준 양식을 다운로드할 수 있다.
2. 표준 양식 외 파일은 검증 단계에서 차단된다.
3. 16개 점수와 Beauty Code가 자동 검증된다.
4. 성공·중복·오류 건수가 분리 표시된다.
5. 오류 행을 Excel로 내려받을 수 있다.
6. 실제 적재는 Master 승인 후 수행된다.
7. Import/Export 작업이 감사 이력에 기록된다.
8. 이름과 이메일이 Import/Export 기본 양식에 포함되지 않는다.
9. 동일 포맷으로 Export 후 수정하여 다시 Import할 수 있다.

## 13. 단계 구분

이번 운영 데이터 관리 검토 브랜치에는 설계와 화면 구조를 반영한다. 실제 Excel 파싱, 오류 파일 생성, DB 적재, 대량 처리 기능은 화면 승인 후 개발한다.
