# LAYAD Supabase 익명 데이터 저장 설계

## 목적

이름, 이메일, 전화번호, 원 IP 주소를 저장하지 않고 다음 데이터를 익명 세션 기준으로 저장한다.

- 테스트 시작/완료 시각
- 테스트 응답과 Beauty Code
- Beauty Code 생성 경로: 테스트 또는 직접 선택
- 접속 국가와 광역 지역
- 선택형 연령대
- 기기 유형
- 상품 분석 요청

원 IP는 애플리케이션 DB에 저장하지 않는다. 국가와 지역은 Vercel 요청 헤더에서 추출한 값만 저장한다.

## 화면 설계

### 1. 첫 화면

하단 안내 문구를 추가한다.

> LAYAD는 이름, 이메일, 전화번호와 원 IP 주소를 저장하지 않습니다. 서비스 개선을 위해 접속 국가·지역, 선택형 연령대, 테스트 응답과 이용 기록을 최소한으로 처리합니다.

`만 14세 이상 이용` 안내를 함께 표시한다.

### 2. 테스트 시작

사용자가 테스트 시작을 누르면 서버에서 익명 세션을 생성한다.

- 무작위 `session_id`
- `started_at`
- `country_code`
- `region_code`
- `device_type`
- `beauty_code_source = test`

화면 진행은 세션 저장 실패로 중단하지 않는다. 저장 실패는 사용자 경험과 분리해 로깅한다.

### 3. 연령대 수집

결과 확인 직전 또는 결과 화면 상단에 선택형 연령대 UI를 배치한다.

문구:

> 서비스 개선을 위해 연령대를 선택해 주세요. 선택하지 않아도 결과를 확인할 수 있습니다.

선택지:

- 14–19세
- 20–29세
- 30–39세
- 40–49세
- 50–59세
- 60세 이상
- 응답하지 않음

정확한 나이와 생년월일은 수집하지 않는다.

### 4. 결과 저장

테스트 완료 시 다음을 저장한다.

- 완료 시각
- 20개 응답
- Beauty Code
- 연령대
- 완료 여부

직접 유형 선택 화면에서는 `beauty_code_source = manual`로 저장한다.

### 5. 상품 분석 요청

상품명 또는 상품 링크 등록 시 익명 세션과 연결한다.

- 입력 유형
- 입력값
- 상태
- 생성 시각

실제 리뷰 분석 전에는 적합도 점수를 생성하지 않는다.

## 데이터 최소화 원칙

저장 금지:

- 원 IP
- 이름
- 이메일
- 전화번호
- 생년월일
- 정확한 좌표
- 브라우저 지문
- 광고 식별자

국가와 지역은 통계 목적의 코드 수준으로만 저장한다. 지역은 가능하면 광역 행정구역까지만 저장한다.

## 서버 처리 흐름

```text
브라우저 요청
→ Next.js Route Handler 또는 Server Action
→ Vercel 헤더에서 국가·지역 읽기
→ 원 IP 미저장
→ Supabase 서버 클라이언트로 익명 세션 INSERT
→ 브라우저에는 session_id만 반환
```

브라우저에서 service role key를 사용하지 않는다.

## 환경변수

```text
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
SUPABASE_SERVICE_ROLE_KEY
```

`SUPABASE_SERVICE_ROLE_KEY`는 서버 전용이며 Vercel 환경변수에만 저장한다.

## AI 토큰 사용

다음 저장 기능에는 AI 토큰이 필요하지 않다.

- 국가/지역 추정값 저장
- 연령대 저장
- 테스트 응답 저장
- Beauty Code 계산 및 저장
- 기기 유형 저장
- 통계 집계

AI 토큰은 리뷰 원문 분석, 특성 코드 추출, 리뷰 요약과 상품별 16유형 적합도 갱신 단계에서만 사용한다.

## 통계와 개인정보 보호

관리자 화면에는 이름과 이메일을 표시하지 않는다. 국가·지역·연령대 통계는 소수 집단이 식별되지 않도록 5건 미만을 묶거나 숨긴다.

## 배포 전 체크리스트

- Supabase 프로젝트 생성
- SQL 마이그레이션 실행
- RLS 활성화 확인
- anon 직접 조회 정책 없음 확인
- service role key가 클라이언트 번들에 포함되지 않는지 확인
- Vercel 환경변수 등록
- Preview와 Production 환경 분리
- 원 IP가 로그 또는 DB 컬럼에 저장되지 않는지 확인
- 연령대 미응답으로도 결과 확인 가능
- 저장 실패 시 테스트 흐름이 중단되지 않음

## 완료 기준

- 익명 세션 생성 가능
- 국가·광역지역만 저장
- 원 IP 미저장
- 연령대 선택 저장
- 테스트 응답과 결과 저장
- 직접 선택 결과 저장
- 상품 분석 요청 저장
- RLS로 브라우저의 임의 조회 차단
- 관리자 통계는 집계 데이터만 사용
