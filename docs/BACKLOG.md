# LAYAD Governed Backlog

## 상태 정의

- IDEA: 논의 중
- DESIGNED: 설계 확정, 미개발
- DEVELOPED: 코드 반영, 배포 미확인
- DEPLOYED: 운영 반영
- VERIFIED: 실제 데이터와 주요 경로 검증 완료

## 우선순위 A — 안정화

| 항목 | 상태 | 비고 |
|---|---|---|
| 관리자 인증 | DESIGNED | 지인 확대 전 필수 |
| 핵심 사용자 경로 회귀 테스트 | DESIGNED | 테스트·직접선택·상품신청 |
| 테스트 데이터 일괄 삭제 검증 | DESIGNED | 실제 데이터 보호 |
| 문서와 코드 현행화 | DESIGNED | 배포마다 갱신 |

## 우선순위 B — 핵심 제품 가치

| 항목 | 상태 | 비고 |
|---|---|---|
| 사용자별 상품 적합도 결과 | DESIGNED | 사용자 유형 점수 최우선 표시 |
| 상품별 16유형 점수분포표 | DESIGNED | 상품당 16행 |
| 16유형 적합도 히트맵 | DESIGNED | 모바일 2열, 데스크톱 4열 |
| 최근 신청의 사용자-상품 적합도 | DESIGNED | 점수·등급·순위 표시 |
| 상품 적합도 결과 DB 저장 | DESIGNED | 검수·공개 상태 포함 |

## 우선순위 C — 분석 고도화

| 항목 | 상태 | 비고 |
|---|---|---|
| 사용자 유형 기준 상품 비교 | IDEA | 적합도 높은 순 |
| 연령대별 상품 관심도 | IDEA | 집계 최소건수 정책 필요 |
| 국가·지역별 적합도 분석 | IDEA | 개인정보 최소화 유지 |
| 자동 AI 분석 | DEFERRED | 비용·품질·법적 검토 후 |
