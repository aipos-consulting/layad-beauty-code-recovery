# LAYAD Master Design

## 1. 제품 정의

LAYAD는 사용자의 Beauty Code를 기준으로 선택한 뷰티 상품이 얼마나 잘 맞는지 알려주는 개인 맞춤형 뷰티 가이드다.

핵심 메시지:

> 선택하신 상품이 회원님의 Beauty Code와 얼마나 잘 맞는지 확인해 보세요.

## 2. 핵심 가치

- 사용자는 자신의 Beauty Code를 이해한다.
- 사용자는 관심 상품이 자신의 유형에 얼마나 적합한지 확인한다.
- 운영자는 상품별 16유형 적합도를 관리한다.
- 서비스는 개인을 식별하는 정보보다 유형·연령대·국가·지역 등 최소 데이터만 사용한다.

## 3. 사용자 경험 우선순위

상품 결과 화면의 정보 순서:
1. 상품명
2. 회원님의 Beauty Code
3. 해당 유형 적합도 점수
4. 감성적인 적합도 설명
5. 16유형 내 순위
6. 유형과 상품 특성의 일치·불일치 이유
7. 16유형 적합도 히트맵
8. 분석 근거
9. 유사 상품 비교

사용자 화면의 표현은 기술 용어보다 자연스럽고 감성적인 문장을 우선한다.

## 4. 관리자 경험 우선순위

관리자 화면의 중심은 단순 신청 건수가 아니라 다음이다.
- 어떤 유형의 사용자가 어떤 상품을 신청했는가
- 그 사용자의 유형과 상품 적합도는 몇 점인가
- 16유형 중 몇 위인가
- 분석 대기·완료·불가 상태는 무엇인가
- 상품별 16유형 점수 분포는 어떠한가

## 5. 데이터 원칙

- 이름, 전화번호, 이메일 등 직접 식별정보는 MVP에서 수집하지 않는다.
- IP 원문은 저장하지 않는다.
- IP에서 파생한 국가·광역 지역만 내부 통계에 사용한다.
- 연령은 정확한 나이가 아니라 연령대로 수집한다.
- 테스트 데이터는 별도 식별값으로 구분하고 일괄 삭제할 수 있어야 한다.

## 6. AI 운영 원칙

MVP에서는 OpenAI API 자동 분석을 기본으로 사용하지 않는다.
- 운영자는 ChatGPT Plus를 분석 보조도구로 사용한다.
- 분석 결과는 운영자가 검토한 후 Supabase에 입력한다.
- 향후 API 자동화는 비용·품질·법적 검토 후 별도 단계에서 진행한다.

## 7. UI 원칙

- 데스크톱과 모바일에서 동일한 기능에 접근할 수 있어야 한다.
- 모바일은 햄버거 메뉴로 전체 관리자 메뉴를 제공한다.
- 한글 단어가 부자연스럽게 중간에서 끊기지 않도록 한다.
- 사용자 화면은 자신의 유형과 상품 적합도를 가장 크게 보여준다.
- 관리자 화면은 조회·검수·운영 상태를 명확히 구분한다.

## 8. 배포 원칙

- 사용자가 명시적으로 개발·배포를 승인하기 전에는 설계만 변경한다.
- 운영 코드와 문서화 작업은 2트랙으로 관리한다.
- Production 변경은 작은 단위로 하고 회귀 테스트를 수행한다.
